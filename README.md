The site is a self-contained static HTML document. English and German contain the same privacy information, including explicitly saved filters and their removal. It uses no first-party cookies, analytics, external fonts or external scripts.

`index.html` must remain byte-identical to `play-store/privacy-policy.html` in the OrbitLens app repository. GitHub Pages deploys from `main`. After each publication, fetch the public URL and compare its bytes and SHA-256 with this file; a Git commit alone does not prove deployment. Current release/publication evidence is recorded in the app repository's `docs/release-readiness.md`.
